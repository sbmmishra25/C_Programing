# 75. Advanced Projects

## 1. Generic Data-Structure Library
Implement vector, list, stack, queue, heap, hash table, and graph APIs using opaque types and callbacks.

## 2. Mini Shell (POSIX)
Implement command parsing, processes, pipes, redirection, and exit status. Clearly mark this as POSIX-specific.

## 3. HTTP-like Server
Build a platform-specific socket server with request parsing, bounded buffers, logging, and robust error handling.

## 4. Memory Allocator Study
Implement a small educational allocator using a fixed arena, free-list blocks, alignment, splitting, and coalescing. Clearly label it educational; do not replace a production allocator without rigorous validation.

## 5. Database Engine Mini-Project
Implement pages, records, indexes, a simple hash/B-tree index, and file persistence.

## 6. Compiler Front-End
Implement lexical analysis, token streams, recursive-descent parsing, and an AST for a small expression language.

## Engineering requirements
Use multiple source files, automated tests, sanitizers, documentation, benchmarks, and explicit platform assumptions. Include failure-injection tests for allocation and I/O errors.
