# 74. Mini-Projects

## Project 1: Student Record Manager
Features: add/update/delete/search/display records, file persistence, validation, sorting, and menu-driven CLI.

Suggested modules:
~~~text
include/student.h
src/student.c
src/storage.c
src/main.c
tests/
~~~

## Project 2: Contact Manager
Use dynamic arrays or linked lists, string handling, search/sort, import/export, and duplicate detection.

## Project 3: Expression Evaluator
Tokenize input, convert infix to postfix, evaluate with stacks, and report syntax errors.

## Project 4: Inventory System
Use structures, hash tables, file storage, sorting, and command-line options.

## Project 5: Graph Analyzer
Read a graph, print traversals, compute connected components, shortest paths, and basic statistics.

## Project standard
Every project should include README, build instructions, input validation, error handling, tests, complexity notes, and ownership documentation.
