# Learning Roadmap

## Phase 1 — Fundamentals
Topics 1–18 establish syntax, data types, expressions, control flow, functions, arrays, and strings.

## Phase 2 — Pointers and Memory
Topics 19–24 build pointer fluency and dynamic allocation.

## Phase 3 — User-Defined Types, Preprocessor, and Files
Topics 25–37 cover structures, unions, enums, typedef, bitwise programming, preprocessing, headers, files, arguments, variadic functions, and qualifiers/storage.

## Phase 4 — Runtime Model, Correctness, and Tooling
Topics 38–46 explain memory layout, lifetime, behavior categories, overflow, debugging, error handling, modularity, multi-file builds, and Makefiles.

## Phase 5 — Data Structures
Topics 47–56 implement linked lists, stacks, queues, trees, BSTs, heaps, hash tables, and graphs.

## Phase 6 — Algorithms
Topics 57–62 develop searching, sorting, recursion, dynamic programming, bit manipulation, and competitive-programming patterns.

## Phase 7 — Advanced C
Topics 63–70 address system-level concepts, low-level memory/pointers, generic APIs, callbacks, reusable libraries, C11/C17/C23, and advanced techniques.

## Phase 8 — Practice and Portfolio
Topics 71–76 consolidate interview preparation, exercises, debugging drills, mini-projects, advanced projects, and the reference index.
